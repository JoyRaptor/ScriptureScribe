## Supplied handoff coverage

All 14 parser items are implemented: ten dash variants with optional spaces; recognized-book matching after prose; Psalm/Pss and Roman/ordinal names; one-chapter books; address validation including LXX Psalm 151; cross-chapter ranges; semicolon continuations; paragraph-bounded v/vv/verse carry; suffixes; period separators; actual chapter-only references; conservative comma lists; exclusion of frontmatter/code/links/URLs; and joined-form comma lists. Raw offsets remain correct for editing and embedding.

Chapter previews, full-passage quotes, abbreviated/carried references, canonical book-key normalization, and complete range links use the same reference model. Quotes are no longer cut at 400 characters.

KJV supplied-word italics are available in previews, study text, and recording cards through a sidecar aligned onto the installed wording. All 31,102 canonical verses were processed; 13,736 have supplied-word emphasis. Forty-four internally missing Enoch addresses are supplied from Charles 1917 and explicitly labeled as supplements. See [DATA-SOURCES.md](DATA-SOURCES.md) for source checks, attribution, and limitations.

Recording cards have full book names, numbered whole-passage pages, Previous/Next through note references, Pin, Close/Esc, optional note emphasis, and contrast text drawn from the note itself. Long passages page before advancing to another reference. The toggle command has a default `Mod+Alt+C` shortcut. Controls preserve editor focus and remain visible on touch devices.

The earlier fix-list items were included: light-theme interlinear English text, the Research-header jump into Bible mode, abbreviated/carried-reference embedding, and native text selection with English/original-word research actions. Native selection is implemented; draggable Android selection-handle behavior still merits an owner usability check.

## Additional changes requested during this session

- Book groups are **Old Testament → New Testament → Apocryphal**. The last category is expanded and scrollable, with no collapse button.
- Book buttons are shorter. On the Note 20, measured button height was 24.7 CSS pixels; Revelation ended at 610 pixels within a drawer ending at 703 pixels. All 66 canonical books fit without scrolling in the tested portrait layout.
- Full-screen card readability and touch controls were checked on the actual phone. Flicker-related changes remove the known stepped word jitter and redundant resizing; subjective animation smoothness still benefits from the owner's eye.

## What lazy dictionary loading changes

Every original dictionary entry is preserved exactly: 19,570 Strong's, 10,714 LXX, and 10,714 LSJ entries. Definitions, original-language study, and lexical search remain offline. The plugin reads the relevant small files on first use and reuses them, instead of parsing the whole lexicon when Obsidian starts. Full word search still loads its complete compact corpus when first requested. This moves a small first-use cost to studying while reducing startup work and memory pressure.

## Build, deployment, and rollback

Run `npm run build`, then `scripts/deploy.ps1` from the project root. Deployment includes `main.js`, `semantic-runtime.js`, `styles.css`, all derived per-book study files, dictionary shards, compact search data, and KJV/Enoch sidecars. Reload the plugin or restart Obsidian after syncing. A main.js-only update is insufficient for this build.

Backups are in `C:/+Projects/Scripture-scribe/review-backups/2026-11-02/`: original source, project build/config files, installed main/styles, and original installed Hebrew/LXX per-book folders. Original monolithic Bible/lexicon JSONs remain installed. To roll back, restore the backed-up installed main/styles and original per-book folders, then restart Obsidian. The older build ignores the added derived files and caches.

The source repository is `C:/+Projects/Scripture-scribe/src/.git`. Changes are uncommitted so they can be reviewed; project-level scripts and assets are outside that source-only repository.
